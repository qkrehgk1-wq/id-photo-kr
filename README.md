# 증명사진 규격 도우미

셀카를 증명사진 규격으로 잘라주고, **그 사진을 내면 반려당하는지 미리 알려주는** 웹앱.
설치·계정·광고 없음. 사진은 기기 밖으로 나가지 않는다.

## 왜 만들었나

시중 증명사진 앱 대부분이 "배경 지워서 여권사진 만들기"를 판다.
그런데 외교부 여권사진 규격에는 이렇게 적혀 있다.

> 편집 프로그램으로 배경 제거/합성 불가

즉 **배경을 지운 여권사진은 규격 위반**이다. 구청에서 반려당하는 흔한 이유가 이것이다.
그래서 이 앱은 용도를 나눈다.

| 모드 | 배경 편집 | 하는 일 |
|---|---|---|
| 여권 · 주민등록증 | **안 함**(규정) | 규격대로 자르기 + 규격 검사 |
| 일반 증명사진 (이력서·사원증·학원) | 함 | 자르기 + 배경 교체 |
| 반명함 3×4cm | 함 | 자르기 + 배경 교체 |

## 기능

- **규격 자동 크롭** — 얼굴을 인식해 정수리~턱 길이와 상단 여백을 규격에 맞춘다
- **규격 검사** — 얼굴 길이(mm), 머리 기울기, 여백, 해상도, 배경 흰색도를 숫자로 판정
- **수평 보정** — 기울어진 머리를 자동으로 세운다 (규격: "머리 기울임 불가")
- **인화시트** — 4×6인치 한 장에 8장 배치. 편의점 무인출력에 그대로 넣으면 된다
  (사진관 약 15,000원 → 편의점 수백 원)

## 규격 근거

[외교부 여권안내 — 여권 사진](https://www.passport.go.kr/home/kor/contents.do?menuPos=32) (2026-08-04 확인)

- 3.5cm × 4.5cm, 온라인 제출 권장 413 × 531 px
- 정수리~턱 3.2 ~ 3.6cm
- 균일한 흰색 배경, 배경 제거·합성 불가
- 무표정, 입 다물기, 정면, 머리 기울임 불가, 컬러렌즈·선글라스 불가
- 6개월 이내 촬영

> 최종 판단은 접수처 기준을 따른다. 이 앱은 사전 점검 도구다.

## 프라이버시

얼굴 사진은 민감정보다. 그래서 **아예 받지 않는 쪽**을 택했다.

- 서버 없음 · 업로드 없음 · 계정 없음 · 추적 없음
- 모든 처리는 브라우저 안에서 끝난다
- 서비스워커도 사진은 캐시하지 않는다 (앱 파일만)
- 얼굴 인식 모델만 CDN에서 내려받는다 → **첫 실행에는 인터넷 필요**

## 기술

- 순수 정적 웹앱 (빌드 단계 없음)
- [MediaPipe Tasks Vision](https://ai.google.dev/edge/mediapipe) — 얼굴 랜드마크 + 셀피 분할, 전부 WASM으로 브라우저에서 실행
- 정수리는 분할 마스크에서 잰다 (얼굴 메시에는 머리카락 위쪽이 없다).
  마스크를 못 쓰면 이마~턱 비율로 추정하고, 추정치를 썼다고 화면에 표시한다

### fail-open

얼굴 인식이나 배경 분할이 실패해도 앱은 계속 쓸 수 있다.
자동이 안 되면 슬라이더로 직접 맞추게 하고, 무엇이 안 됐는지 알려준다.

## 개발

```bash
node --test test/geometry.test.mjs
```

크롭 좌표·비율·인화 배치는 전부 `js/geometry.js`에 순수 함수로 모아 두고 테스트로 고정했다.
증명사진 앱에서 조용히 틀리기 쉬운 곳이 전부 여기다.

로컬 실행:

```bash
python -m http.server 8765
```

카메라는 `localhost` 또는 HTTPS에서만 열린다.
